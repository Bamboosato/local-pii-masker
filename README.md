# Local PII Masker

日本語テキストに含まれる個人情報・機密情報を、ブラウザ内で検出して可逆的にマスキングするWebアプリケーションです。

原文、検出結果、マスク対応表はサーバーへ送信せず、現在のブラウザセッション内だけで扱います。マスク済みテキストを外部の生成AIなどへ渡し、回答内に保持されたマスクトークンをローカルで元の文字列へ置換する利用を想定しています。

> 本アプリの「復元」は、外部AIの回答などに残っているマスクトークンを元の文字列へ置換する機能を指します。AIによって削除・改変された情報を意味的に復元するものではありません。

## MVPの目的

- 日本語テキストから個人情報・機密情報の候補を検出する
- ユーザーが検出結果を確認・修正できるようにする
- 原文とマスク結果を比較し、マスク漏れを確認できるようにする
- マスク済みテキストを外部サービスへ安全に受け渡しやすくする
- 外部サービスの回答に残ったトークンをブラウザ内で復元する

## 想定利用フロー

1. 原文を入力または貼り付ける
2. 正規表現とローカルNERで候補を検出する
3. 候補を承認・除外し、必要な対象を手動で追加する
4. 「原文」と「マスク結果」を切り替えて確認する
5. マスク済みテキストをコピーし、外部の生成AIなどへ渡す
6. 外部サービスの回答を貼り付ける
7. 回答内のマスクトークンを元の文字列へ置換する

## MVPの主要ルール

- 同一文字列は、原文中の全出現箇所を一括してマスクする
- 出現箇所ごとの個別指定は行わない
- `山田`と`山田太郎`のような包含関係にある文字列を両方登録できる
- 同じ位置で複数の対象が一致する場合は最長一致を優先する
- 原文は編集可能、マスク結果は読み取り専用とする
- マスク結果は原文とマスク対象一覧から都度生成する
- ユーザーデータはメモリ内だけに保持し、ページ更新・タブ終了時に破棄する
- AIモデルなどの公開資材はブラウザキャッシュを利用できる

## MVPの前提環境

- 主対象：PC
- OS：Windows 11、macOS
- 正式対応候補：Google Chrome最新版
- 準対応候補：Microsoft Edge最新版
- ネットワーク：安定したブロードバンド環境を推奨
- 対象言語：日本語
- スマートフォン、タブレットは正式対応外

## 技術方針

| 項目 | 方針 |
| --- | --- |
| フロントエンド | React + TypeScript + Vite |
| NER実行基盤 | Transformers.js |
| モデル形式 | ONNX |
| 初期モデル候補 | `jiting/xlm-roberta-ner-japanese_onnx`（評価後に決定） |
| 構造化PII検出 | 正規表現・検査ロジック |
| AI推論 | Web Workerでの実行を推奨 |
| 永続保存 | MVPでは行わない |
| 外部生成AI連携 | API連携せず、コピー＆ペーストで利用する |
