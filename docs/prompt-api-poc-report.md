## 2026-10-27 Prompt API unavailableの原因調査

### 結論と再現条件

今回の直接原因はPlaywright 1.61.1の既定引数 `--disable-features=...OptimizationHints...`。同じ診断用の通常プロファイル、同じChrome、同じlocalhostページで、当該1項目だけを変更するA/B/Aを逐次実行した。`LanguageModel` のモックやモデルの強制指定は使っていない。

| 順序 | 起動条件 | ja/text | en/text |
| --- | --- | --- | --- |
| A | Playwright既定（OptimizationHintsを無効化） | unavailable | unavailable |
| B | 複合disable-featuresからOptimizationHintsだけを除去 | downloadable | downloadable |
| A再実行 | 同じプロファイルで既定引数へ戻す | unavailable | unavailable |

いずれもsecure context、トップレベル、`language-model` 許可ポリシーを確認した。別途、非永続コンテキストでもB条件では日本語がdownloadableになったため、今回の直接原因を非永続コンテキストだけに帰さない。モデル取得や推論のためには、再起動後も状態を保持できる専用の通常プロファイルを推奨する。

既定引数では `--disable-background-networking`、`--disable-component-update`、`--disable-field-trial-config` 等も存在する。Bではこれらを維持しているため、今回の利用可否の差をこれらの除去効果と混同しない。ただし実際のモデル取得では更新・背景通信の抑止も妨げとなり得るため、通常Chromeで準備する手順と分ける。

補助的な実装根拠として、調査時点のChromiumソースは、OptimizationHintsが無効ならOptimizationGuideKeyedServiceを返さず、モデルbroker clientなしの場合にUnavailableServiceNotRunningを返す構造だった。これはmainブランチの補助資料であり、実行バイナリ155.0.8059.85と同一のソース版を証明したものではない。因果の根拠は上の実機A/B/A結果を優先する。
