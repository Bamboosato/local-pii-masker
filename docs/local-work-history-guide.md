# マスク対応表の保存・再利用ガイド

## 保存するもの

「対応表を保存」では、マスク対象文字列とマスク文字列（トークン）の対応、復元文字列、種別、検出元など、再適用と復元に必要なデータだけを暗号化してブラウザ内のOPFSへ保存します。

原文、マスク結果、外部回答、復元結果、出現位置、画面状態は保存されません。

対応表名は暗号化されません。氏名、住所などの個人情報を入力しないでください。

## 保存する

1. 有効なマスク対象を確認します。
2. メニューの「マスク対応表」から「対応表を保存」を選びます。
3. 保存済み対応表がある場合は、「既存の対応表を上書き」または「新しい対応表として保存」を選びます。
4. 対応表名と12文字以上のパスフレーズを入力します。
5. パスフレーズを確認して保存します。

鍵とパスフレーズは保存されません。上書き時は入力したパスフレーズで再暗号化します。

## 新しい原文で使う

1. 原文を入力または貼り付けます。
2. メニューの「マスク対応表」から「保存済み対応表を管理」を選びます。
3. 一覧から対象行の「開く」を選びます。
4. 別ダイアログで対応表名を確認し、パスフレーズを入力して「対応表を開く」を選びます。
5. 対応表が現在の原文へ再適用され、マスク結果を確認できます。

対応表を開いても、以前の原文や画面は復元されません。現在のマスク対象がある場合は、置き換え確認が表示されます。外部回答を入力中の場合は、トークン対応の混在を防ぐため先に空にしてください。

## マスク済み文章を復元する

新しい文章に対応表のトークンが残っていれば、既知トークンを復元できます。不明トークンは変更されず、画面に警告されます。トークンに似た文字列の扱いを含め、復元結果は送信前に確認してください。

## 削除する

- 行の「⋮」メニューにある「対応表を削除」：一覧から選んだ1件だけを削除します。
- 一覧下部の「保存済み対応表をすべて削除」：アプリが管理するOPFS内の対応表、一覧、バックアップを削除します。確認には実際の保存件数が表示され、削除後も管理画面は空状態で開いたままです。
- 「現在の作業を消去」：画面上の原文・候補・外部回答だけを初期化します。保存済み対応表は削除しません。

現在の作業の消去と保存済み対応表の削除は別の確認操作です。

## 利用できない場合

OPFS非対応、容量不足、権限拒否などの場合、対応表の保存・一覧・再利用は利用できません。その場合も、原文入力、検出、手動追加、マスキング、コピー、復元は一時利用できます。原文は保存されません。
