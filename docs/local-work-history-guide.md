# ローカル作業履歴 保存・復元ガイド

## 保存する

1. 原文とマスク対象を確認する。
2. メニューから「現在の作業を保存」を選択する。
3. タイトル、12文字以上のパスフレーズ、確認用パスフレーズを入力する。
4. 保存内容と注意事項を確認して確定する。

タイトルは暗号化されません。氏名、住所などの個人情報を入力しないでください。

保存後も、外部回答と復元結果は保存されません。必要な場合は、復元前に外部回答を再度貼り付けてください。

## 開く・上書きする

メニューの「保存済みの作業を開く」から履歴を選び、パスフレーズを入力します。復元されるのは原文、マスク対象、マスク設定です。マスク結果は再生成されます。

保存済み作業の上書き保存では、パスフレーズを再入力します。別の履歴として保存したい場合は「名前を付けて保存」を使用します。

未保存変更がある状態で別の作業を開く場合は、「現在の作業を保存」「保存せずに開く」「キャンセル」から選択します。外部回答の変更だけでは未保存変更とは判定しません。

## 消去する

- 「現在の作業を消去」：画面上のインメモリ作業だけを消去し、保存済み履歴は残す
- 「保存済みの作業を全削除」：このアプリが管理するOPFS内の履歴を削除し、画面上の作業は自動消去しない

削除した保存データは元に戻せません。

## 利用できない場合

OPFS非対応、容量不足、アクセス拒否などの場合、保存・復元・履歴一覧を利用できないことがあります。その場合も、一時的な原文入力、検出、マスキング、コピー、復元は継続して利用できます。
